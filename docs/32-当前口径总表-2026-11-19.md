## 3. 当前阈值（两套口径，**不同指标，不是重复配置**）

| 口径 | 用途 | 阈值 | 唯一来源 |
|---|---|---|---|
| 三态报告（`pass/review/fail`） | 决定哪些件进转换/抽题 | 异常字符比 ≥ **0.02** → fail；CJK 比 < **0.15** → review；字符数 < **100** → fail | `mianjing_kb/gate.py` 的 `TH_BAD/TH_CJK/TH_MIN`（`TH_CJK` 直接引 config） |
| 四态台账（`gate_results`） | 记录文本质量（`pass/low_cjk/garbled/non_content`） | 乱码比 > **0.01**；有效字符比 < **0.90**；可见字符 < **800** | `mianjing_kb/kb/config.py` 的 `GATE_GARBLED_MAX / GATE_VALID_MIN / GATE_MIN_VISIBLE / GATE_CJK_MIN` |

原则：**CJK 下限单源（0.15）**；其余数值服务于不同问题（"分流" vs "台账分档"），不强行合并。
调参只改上述两处，禁止在脚本里另写一套数；聚类参数是 CLI（`report/canonical --dist/--jac`），评测基线见 `30`。

## 5. 稳定键契约（现状与目标）

| 对象 | 现用键 | 稳定性 | 结论 |
|---|---|---|---|
| `source_documents` | `doc_hash`（sha256[:16]） | 稳定 | **唯一可跨库引用的源键** |
| `questions` | `qid` + `UNIQUE(doc_hash, seq)` | 重切即漂移 | `qid` 只作行号，禁止跨库关联 |
| `label_facts` | `q_norm_hash` | 题干改一字失联 | 过渡方案（靠 `store()` 重挂） |
| `vec_questions` | `rowid = qid` | 重建即错配 | 依赖 `--reembed`，G4 只比数量 |
| `canonical_questions` | `sha(q_norm(代表题干))` | 代表变体变则换 ID | 已知不稳定 |
| `question_variants` | `sha(doc_hash:seq)` | 随 seq 漂移 | 同上 |

**目标键**：`(doc_hash, q_norm_hash)` 作为向量表外部主键与标签外键；`refresh` 默认 `--reembed`，
`copy_vec` 改为显式 flag + 题集哈希校验，不一致 ABORT。**状态：未实现，待办 T29。**
