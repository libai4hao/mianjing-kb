# 切题标注标准 v1（2026-11-20）

> 状态：现行（v1） · 最后更新：2026-11-20 · 适用版本：无

## 1. 目的与适用范围

本标准用于面经题库切题/切答案环节的人工标注、复核和坏例归因，覆盖：

- 文档层：来源公开性、内容类型、隐私与权威性
- 单元层：题干/答案切分、Q/A 质量判定、修正与处理决策
- 复发错误：错误码、case_group、规则/排除记录

本标准不替代抽取代码的自动规则；它定义人工判断口径，以及自动填写和人工填写的边界。

## 2. 当前批次默认口径

| 项 | 默认值 | 说明 |
|---|---|---|
| 来源公开性 | `source_scope=public` | 当前批次先默认公开；保留字段，后续可改 personal/mixed/unknown |
| 公开状态 | `publication_status=public_no_url` | 公开但暂未补 URL；不能写成 `public_url` |
| 来源置信度 | 每篇文档一个值，默认 `medium` | 同一 `doc_hash` 只保留一个值；母版按 doc_hash 继承 |
| 标注人 | `annotator=master` | 当前批次统一 |
| 标注日期 | `annotated_at=2026-11-20` | 当前批次统一；后续修改按实际日期 |
| 内容类型 | 按目录预填 | 题库=`question_bank`、面经=`interview`、真题=`exam`、专题笔记=`note` |

`public` 只表示“按当前批次默认按公开处理”，不表示已经核验公开 URL。没有 URL 的公开来源只能记 `public_no_url`；`unknown` 不得默认当 `public`。

## 3. 列定义（母版 35 列）

### 3.1 只读列

| 列 | 定义 | 说明 |
|---|---|---|
| `sample_id` | 原 1000 样本编号 | `S0001–S1000`，不改 |
| `qid` | 题库题目 ID | 不改 |
| `doc_hash` | 文档哈希 | 对应 `raw_docs_manifest.csv` |
| `md_rel` | 文档相对路径 | 不改 |
| `source_file` | 原始文件 | pdf/docx/txt 文件名 |
| `span_start` | 管线文本起始偏移 | `text_of` 字符偏移，不是原始 Markdown 字节位置 |
| `span_end` | 管线文本结束偏移 | 同上 |
| `answer_missing` | 管线是否判答案缺失 | `0/1`，不改；人工用 `a_verdict` 复判 |
| `q_text` | 当前题干 | 不直接改；修正写 `corrected_q_text` |
| `a_text` | 当前答案 | 不直接改；修正写 `corrected_a_text` |

### 3.2 来源列

| 列 | 填写 | 定义 | 取值 |
|---|---|---|---|
| `source_scope` | 条件 | 个人面经/公开面经的公开性与归属；留空=继承文档层 | `personal`/`public`/`mixed`/`unknown` |
| `source_kind` | 预填可改 | 内容形态 | `interview`/`question_bank`/`exam`/`note`/`other` |
| `answer_authority` | 条件 | 答案权威性 | `official`/`curated`/`aggregated`/`first_person`/`secondary`/`unknown` |
| `canonical_eligible` | 条件 | 是否允许进入 canonical 合并 | `yes`/`no`/`review` |
| `privacy_level` | 条件 | 隐私级别 | `high`/`medium`/`low` |
| `scope_confidence` | 自动+条件 | 来源判定置信度；同一文档一个值 | `high`/`medium`/`low` |

### 3.3 结构列

| 列 | 填写 | 定义 | 取值 |
|---|---|---|---|
| `unit_type` | 必填 | 单元形态 | `question`/`noise`/`context_only`/`ignore` |
| `is_question` | 必填 | 是否单独成题 | `1`/`0` |
| `q_line_start` | 选填 | 题干起始行 | 整数或空 |
| `q_line_end` | 选填 | 题干结束行 | 整数或空 |
| `a_line_start` | 选填 | 答案起始行 | 整数或空 |
| `a_line_end` | 选填 | 答案结束行 | 整数或空 |

行号以管线文本为准；不确定时留空，用 `span_start/end` 和 `source_text` 复核。

### 3.4 质量列

| 列 | 填写 | 定义 | 取值 |
|---|---|---|---|
| `q_verdict` | 必填 | 题干本身是否独立、完整、单一、边界正确 | `correct`/`minor`/`wrong`/`not_question`/`unknown` |
| `a_verdict` | 必填 | 答案是否正确回答本题、是否归属本题 | `correct`/`partial`/`wrong`/`missing`/`misattached`/`not_applicable`/`unknown` |
| `quality` | 必填 | 整体档位，不代替 Q/A 原因 | `good`/`minor`/`bad` |
| `q_error_code` | 条件 | 题干主错误码 | 见 §5 |
| `a_error_code` | 条件 | 答案主错误码 | 见 §5 |

### 3.5 处理、修订与审计列

| 列 | 填写 | 定义 | 取值 |
|---|---|---|---|
| `decision` | 必填 | 最终处理 | `accept`/`fix_q`/`fix_a`/`fix_both`/`split`/`exclude`/`review` |
| `case_group` | 选填 | 复发错误聚类名 | 常用组或自定义 |
| `rule_id` | 选填 | 规则/排除记录 ID | 字符串或空 |
| `corrected_q_text` | 条件 | 修正题干 | 完整题干；正确则留空 |
| `corrected_a_text` | 条件 | 修正答案 | 完整答案；不能编造 |
| `note` | 选填 | 一句话备注 | 多个错误码在此列全 |
| `annotator` | 必填 | 标注人 | 姓名/代号 |
| `annotated_at` | 必填 | 日期 | `YYYY-MM-DD` |

## 4. Q/A 四象限

| 场景 | q_verdict | a_verdict | quality | decision | 修正 |
|---|---|---|---|---|---|
| 两边都对 | `correct` | `correct` | `good` | `accept` | 都留空 |
| Q 对 A 错 | `correct` | `partial/wrong/missing/misattached` | `minor/bad` | `fix_a` | 只填 `corrected_a_text` |
| Q 错 A 对 | `minor/wrong` | `correct` | `minor/bad` | `fix_q` | 只填 `corrected_q_text` |
| 两边都错 | `wrong/not_question` | `wrong/missing/misattached` | `bad` | `fix_both/exclude/review` | 可修才填两列 |

`quality` 口径：

- `good`：`q=correct` 且 `a=correct/not_applicable`
- `minor`：只有 `q=minor` 或 `a=partial`
- `bad`：任一侧 `wrong/missing/misattached/not_question`，或题干不可判定

## 5. 错误码

### 题干侧

- `E_STEM_SPLIT`：题干被切碎
- `E_MULTI_Q`：多题并一题
- `E_SECTION_HEADER`：章节标题被当题
- `E_CODE_FRAGMENT`：代码片段被当题
- `E_EXAM_INSTRUCTION`：考试指令被当题
- `E_TOC`：目录被当题
- `E_TABLE`：表格参数被当题
- `E_AUTHOR_INTRO`：作者介绍被当题
- `E_PROMO`：广告/公众号被当题
- `E_SCOPE_MISSING`：来源不明

### 答案侧

- `E_ANSWER_MISSING`：答案缺失
- `E_ANSWER_BLEED`：下一题题干/上一题答案串入
- `E_SEPARATOR_AS_ANSWER`：分割线/页码被当答案
- `E_ANSWER_PARTIAL`：答案不完整
- `E_ANSWER_WRONG`：答案事实错误
- `E_ANSWER_MISATTACHED`：答案归属错
- `E_PRIVATE_DETAIL`：个人隐私细节

一条单元只填一个主错误码；多个问题写进 `note`。

### 5.1 `case_group` 常用组

| case_group | 含义 | 典型错误码 |
|---|---|---|
| `stem_split` | 题干被切碎 | `E_STEM_SPLIT` |
| `answer_bleed` | 答案串到下一题/上一题 | `E_ANSWER_BLEED` |
| `answer_partial` | 答案不完整 | `E_ANSWER_PARTIAL` |
| `answer_wrong` | 答案事实错误 | `E_ANSWER_WRONG` |
| `author_intro_between_q` | 题间作者介绍/广告 | `E_AUTHOR_INTRO`/`E_PROMO` |
| `toc_as_question` | 目录被当题 | `E_TOC` |
| `code_fragment` | 代码片段被当题 | `E_CODE_FRAGMENT` |
| `table_as_answer` | 表格/参数被当答案 | `E_TABLE` |
| `separator_as_answer` | 分割线/页码被当答案 | `E_SEPARATOR_AS_ANSWER` |
| `multi_q` | 多题并一题 | `E_MULTI_Q` |
| `private_detail` | 个人隐私细节未掩码 | `E_PRIVATE_DETAIL` |
| `scope_conflict` | 来源公开性冲突 | `E_SCOPE_MISSING` |

同一 `case_group` 在 3 篇以上文档或 5 个以上单元复发，升级为规则/排除项，不只改单条。

## 6. 来源、权威性与 canonical

| source_scope | answer_authority 默认 | canonical_eligible 默认 | privacy |
|---|---|---|---|
| `personal` | `first_person` | `no` | `high` |
| `public` + `interview` | `aggregated` | `review` | `medium` |
| `public` + `question_bank` | `curated` | `yes` | `low` |
| `public` + `exam` | `official` | `yes` | `low` |
| `public` + `note` | `secondary` | `review` | `low` |
| `mixed/unknown` | 按段落最严格值 | 默认 `review` | 默认 `high` |

`quality=good` 只说明切题结果可用，不说明能进 canonical。个人面经即使 Q/A 都对，仍是 `first_person`、`canonical_eligible=no`。

## 7. 来源判定

- `personal`：本人/小范围私有记录，未公开发布；如个人笔记、聊天导出、`我的面经` 目录。
- `public`：公开渠道可获取，有 URL/公开账号/发布记录；第一人称也算 public。
- `mixed`：同一文档同时有个人私有段落和公开转载/汇编；按单元覆盖 `source_scope`。
- `unknown`：无证据；默认按 personal 的隐私级别处理，不默认 public。

不得用“我/本人”判断公开性。第一人称公开博客仍是 public；个人笔记里转述别人的面经仍是 personal。

## 8. 清洗与边界口径

### 8.1 `答:` 开头

- 只去掉 `corrected_a_text` 开头的一个 `答:` / `答：` / `A:` / `A：` 标签，保留回答正文。
- 原始 `a_text` 不改，保留回放证据。
- 题干同理：`问:` / `Q:` 开头只在修正题干时去掉标签，原始 `q_text` 不改。

### 8.2 多题串行

- 在下一题标题、下一篇/下一节标题、另一个明确问题处截断。
- `corrected_a_text` 只保留本题答案；不把下一题的缓存/重定向/其他主题并入。
- 若同一段含多个子问题，按原题问法保留必要的并列结构；不把独立下一题硬塞进来。

### 8.3 广告、作者介绍、参考资料

- 广告、公众号、二维码、联系方式、作者介绍、参考资料、版权声明：从 `corrected_a_text` 删除。
- 题间/答案区的作者介绍：原文 `a_text` 保留，`a_error_code=E_ANSWER_BLEED` 或 `E_PRIVATE_DETAIL`；`corrected_a_text` 只留答案正文。
- 参考资料链接不能当答案；需要时写进 `note`，不混入答案。

### 8.4 图片缺失

- 原文有“如下图/见图/对比图”但没有图片：删除指代句，改写为文字结论，不能保留指向不存在图片的句子。
- 不能凭记忆补图或补数据。

### 8.5 空行、分割线、页码

- 连续空行折叠为段落分隔；不保留四五个空行。
- `-----`、`***`、`___`、装饰线、页码、页眉页脚：从答案正文删除。
- 分割线前后都是答案文字时，用段落分隔，不直接粘连。
- 答案只有空行/分割线/页码：`a_verdict=missing`、`E_ANSWER_MISSING` 或 `E_SEPARATOR_AS_ANSWER`。

### 8.6 异常换行

- 中文句子被 PDF/OCR 在词中间断行：合并为完整句子。
- 列表、代码、命令、HTTP 头字段保留原行，不强行合并。
- 压缩/解压示例中的 `Accept-Encoding:` 等命令行保留独立行。
- 已知局限（2026-11-21）：源 MD 中另有「汉字 空格 汉字」的**词中空格**（如「调 用」「实 现」「一 个」），与上条的词中断行（换行符）不同——它来自上游 PDF 文字层（pymupdf4llm），切题器原样保留、不自动删。全库 1434 篇中 930 篇命中、约 11.6 万处，其中既有此类词中空格，也有标题/图注的合理空格（如「图 原」）；无分词词典无法安全区分，无差别删除会制造新错误。标注时若仅因此造成瑕疵，记 `q_verdict=minor` 按现状接受，不单列 `E_` 错误码；OCR 错字（如「说 氵 去」）属转换层错字，删空格也不能恢复。
- 已知结论（2026-11-21）：跨行 LaTeX / KaTeX 公式（如 `{{< katex display >}}...\begin{aligned}...\end{aligned}...{{< /katex >}}`）在真实语料中已实测**不会被拦腰截断**——公式行不满足题目起点正则，作为答案正文整段保留，item 内 `\begin{}`/`\end{}` 全部配对完整；代码围栏（R3）亦已覆盖。无需新增「公式原子化」规则。注意语料中大量 `$$` 是 shell 变量 / CGLIB 类名噪声（如 `Chinese$$EnhancerByCGLIB$$`），不可当公式围栏。

### 8.7 超长文本

- Excel 单元格上限 32,767 字符；本批 S0010 修正答案约 1,035 字，已加高第 5 行到 409，能显示完整内容。
- 若未来答案超过 32,767：全文存独立 `长答案` 表（`sample_id,column,text`），`corrected_a_text` 存摘要 + 指针；不得静默截断。
- 不因为列宽/行高看不到就把内容删掉。

### 8.8 剔除清单

| 内容 | 独立成单元时 | 混在答案内部时 |
|---|---|---|
| 作者介绍、公众号、版权、广告、二维码、关注引导 | `unit_type=noise`、`is_question=0`、`decision=exclude` | 删除；`a_error_code=E_ANSWER_BLEED` 或 `E_PROMO` |
| 目录、章节标题、习题编号 | `case_group=toc_as_question`、`decision=exclude` | 截断；`E_ANSWER_BLEED` |
| 页眉页脚、页码、分割线、装饰线 | `case_group=separator_as_answer`、`decision=exclude` | 删除；仅剩这些则 `a_verdict=missing` |
| 参考资料、延伸阅读、纯链接 | `unit_type=noise`、`decision=exclude` | 删除；答案只有链接则 `a_verdict=missing` |
| 私人姓名、联系方式、公司内部信息 | `case_group=private_detail`、`decision=exclude` | 掩码或删除；`E_PRIVATE_DETAIL` |
| 与本题无关的扩展阅读 | `unit_type=context_only`/`ignore` | 截断，不并入本题答案 |

剔除只改 `decision` 和 `corrected_*`，不删除原始 `q_text/a_text`；原始文本保留用于回放和复核。

## 9. 标注流程

1. 读文档层：确认 `source_scope/source_kind`；同一文档只在 `文档来源` 定一次 `scope_confidence`。
2. 判单元：`unit_type`、`is_question`；噪声/目录/作者介绍先 `exclude`，不进入 Q/A 判定。
3. 判题干：独立、完整、单一、边界正确；填 `q_verdict`、`q_error_code`。
4. 判答案：是否正确回答本题、是否归属本题；填 `a_verdict`、`a_error_code`。
5. 定档：按四象限填 `quality`；按处理能力填 `decision`。
6. 修正：只有 `fix_q/fix_a/fix_both` 才填 `corrected_*`；按 §8 清洗，不编造。
7. 归因：复发错误填 `case_group`；有规则/排除项填 `rule_id`；多错误写 `note`。
8. 签名：`annotator`、`annotated_at`。
9. 复核：第二人抽 10%，`bad` 与 `fix_both/exclude` 全复核；重点看答案归属和截断点。
10. 聚类：按 `case_group` 汇总；达到 3 篇/5 单元阈值就升级规则或排除项，再重跑样本验证。

## 10. 自动填写规则

按以下顺序自动填，人工可覆盖：

1. `source_scope=public`（当前批次默认）
2. `source_kind`：按目录预填
3. `answer_authority`：interview→aggregated；question_bank→curated；exam→official；note→secondary
4. `canonical_eligible`：interview/note→review；question_bank/exam→yes
5. `privacy_level`：interview→medium；其它 public→low
6. `scope_confidence`：每篇文档取已填值；无值默认 medium
7. `unit_type=question`、`is_question=1`
8. `answer_missing=1` 且未判：`a_verdict=missing`、`a_error_code=E_ANSWER_MISSING`
9. `annotator=master`、`annotated_at=2026-11-20`

不自动填：`q_verdict`、`a_verdict`（除 missing）、`quality`、`decision`、`corrected_*`、`case_group`、`rule_id`。这些必须人工判。

## 11. 母版操作

- 母版不合并表头；A–E 冻结，F 以后所有列均可选中、拖动列宽、隐藏。
- 母版不内嵌“原文”表；34 篇对应 Markdown 原文放在样例目录的 `source_md/` 下，按 `md_rel` 保留目录结构。
- 每题到 md 的对应关系见 `sample_source_index.csv`；`span_start/span_end` 是 `text_of` 后字符偏移，不是原始 Markdown 字节位置。
- 非核心列已按组设置分级：来源 K–P、结构 Q–V、质量 W–AA、决策 AB–AD、修订 AE–AF、审计 AG–AI；可用列组按钮折叠。
- `case_group` 有下拉常用组，也允许直接输入新组；无强制错误提示。
- `source_scope`、`scope_confidence` 在普通文档留空/继承 `文档来源`；只有混合文档才在单元行覆盖 `source_scope`。
- 修改 `文档来源` 后，母版按 `doc_hash` 重新继承；不要一行一行改同一文档的置信度。

## 12. 复核与验收

1. 每篇文档只有一个 `scope_confidence`；同一 doc_hash 不出现两个值。
2. `public_no_url` 不得写成 `public_url`；无 URL 不编 URL。
3. `corrected_a_text` 不含 `答:` 标签、分割线、页码、广告、下一题内容、图注指代。
4. `corrected_a_text` 不编造原文没有的答案；原文不可修就 `exclude`。
5. 个人面经 `first_person` 不进入 canonical。
6. 所有 `fix_*` 必须对应 `q_error_code`/`a_error_code` 或 `case_group`。
7. 复发错误同一 `case_group` 在 3 篇或 5 个单元以上，升级规则/排除。
8. 100 条样本重跑后，切题边界、答案归属、空行/分割线清洗无回归。
9. `source_md/` 中 34 篇 md 与 `source_md_index.csv` 一致；`sample_source_index.csv` 的 100 条均指向存在的文件。
