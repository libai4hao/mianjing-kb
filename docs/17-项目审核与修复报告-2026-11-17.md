## 2. P0-2 根因更正（审核过程中的重要发现）

初判"verify_ledger.py 未落地导致链路断裂"**不准确**。真相是门禁存在三个实现且语义漂移：

| 实现 | 位置 | 输出 | 状态判定 |
|---|---|---|---|
| 语料侧 gate.py（320 行，生产在用） | `…\21-面经数据库\tools\gate.py` | `{summary, thresholds, rows, collisions}` | 三态 pass/review/fail + NFKC |
| 仓库 gate.py（122 行，修复前） | `tools/gate.py` | `{"summary","results"}` | 四态 pass/garbled/low_cjk/non_content，无 NFKC |
| 计划中 verify_ledger.py | **未落地**（docs/15:25/49 承诺） | G1-G7 | — |

dispatch.py / ocr_merge.py 绑定的是语料侧三态产物（`report["rows"]` 的
`state/rel/md` 字段）。仓库版 gate.py 的输出下游根本读不了——一旦按 docs/04 的
SOP 重跑 `gate.py --out build\gate_report.json` 会用不兼容格式覆盖生产报告，
随后 dispatch / ocr_merge 双双 KeyError。

**修复方向（用户拍板）**：仓库 gate.py 升级为三态 + NFKC + rows 结构，与
dispatch/ocr_merge 自洽；语料侧 320 行 gate.py 降级为历史参考。

## 3. 修复明细

### P0-1 test_cluster.py 测试隔离（含 P2-5 空壳断言）
- fixture `tiny_corpus` 补 `monkeypatch.setattr(cl.config, "BUILD_DIR", build)`
  （`BUILD_DIR` 是 import 期常量，patch `CORPUS_ROOT` 不会让它跟着变——对照
  test_review_cli.py:16-18 的正确写法）；
- 空壳断言 `assert (tiny_corpus.parent is not None)` 改为真断言：
  `cluster_pending.csv` / `cluster_sample50.md` 必须存在于**临时** build。
- 验证：`pytest tests/test_cluster.py` → **4 passed**。

### P0-2 gate.py 重写（含 P2-4 doc_hash、P3-7 --recursive）
- 判定对齐语料侧三态：先 NFKC 归一 → chars<100 fail → bad≥2% fail →
  cjk<15% review → pass（阈值 TH_MIN/TH_BAD/TH_CJK 与语料侧一致）；
- 双入口：`--md-dir`（独立门禁，rows.rel=md 相对路径）+ `--audit`（生产口径：
  按 BUILD/convert_log.json ok 件驱动，rows.rel=源路径，**与 dispatch/ocr_merge
  直接兼容**，默认写 BUILD/gate_report.json）；
- P2-4：`--audit` 的 rows 补真 `doc_hash`（源文件 sha256 前 16 位）；
  `--md-dir` 台账口径保持 NULL 并注释原因（md 产物与源非一一对应，schema 001 注释原话）；
- P3-7：删除失效的 `--recursive` 参数（rglob 恒递归）；
- gate_results 台账（schema 001 四态口径）不动：--md-dir 模式继续写
  textmetrics 四态 verdict，与三态报告各司其职（台账答"文本质量"，报告答"哪些件分流"）；
- test_gate.py 同步适配三态断言。
- 验证：`pytest tests/test_gate.py tests/test_textmetrics.py` → **6 passed**；
  `--audit` 冒烟（生产 registry+convert_log，423 件）：rows 结构
  `rel,md,doc_hash,exists,drift,state,reason,chars,cjk,latin,bad,fixed,head`，
  doc_hash 非空 416/423（7 件源已删属合理），state 分布 pass=352/review=5/fail=66。
