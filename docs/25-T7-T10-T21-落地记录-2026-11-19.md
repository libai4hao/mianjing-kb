## T21 标签体系补全 + 归一

### 1. 单一来源

| 文件 | 作用 |
|------|------|
| `meta/label_schema.yaml` | 7 个维度的 kind/枚举/范围/单多选/上限/是否必填 |
| `meta/tag_vocab.yaml` | 二级推荐词表（8 组 34 个），prompt 提示用，**不强制封闭** |
| `meta/tag_synonyms.yaml` | 约 40 条别名/缩写/英文 → 规范标签 |
| `mianjing_kb/kb/labelspec.py` | schema 读取（缺失降级 DEFAULT_SCHEMA）+ 校验 + 归一 |

字段口径：

- `topic`：词表并集 + 「其他」兜底，≤40 字；
- `qtype`：八股/算法/HR/场景/项目（`batch_label` 与 `verify_ledger` 不再各写一份）；
- `difficulty`：1–5 整数；
- `position`：后端/前端/算法/测试/客户端/数据/其他，多选 ≤2；
- `quality`：重复/残缺/过时/广告/无答案，多选 ≤3；
- `canonical_q`：标准化问句 ≤60 字（空则回退题干前 60 字）；
- `tags`：开放提取 → 同义词归一 → 去重 → ≤8 个、每个 ≤24 字。

### 2. 迁移 012

`012_label_dimensions`（`kb/db.py`）给 `questions` 与 `labels_staging` 加
`position` / `quality` / `canonical_q`，`labels_staging` 另加 `tag_norm_hits INTEGER`；
逐列判存在，中断重跑只补缺列；`REQUIRED` 自检同步加列。

### 3. 打标链路

- `batch_label.build_system_prompt(vocab)` 按 schema 渲染 prompt（含岗位/质量/标准化问句/标签上限）；
  `SYSTEM` 仍作为"无词表"基线常量保留。
- `label_one` 用 `labelspec.validate_label`：
  - topic 词表外 → 「其他」+ `review_state='pending'`；
  - position/quality 越界值丢弃 + pending；
  - tags 同义词归一，`tag_norm_hits` 记录命中数；
  - qtype/difficulty 非法 → `ValueError` 进 `label_failed.jsonl` 重试。
- `write_staging` / `merge` 同步新列；`label_facts` 保持四列口径不变。

### 4. G6 扩维度

- 历史 staging 行没有新列 → 不误判（仍在 0.95 schema 合格率口径内）。
